              Security notes

              • The server binds to 127.0.0.1 by default. Loopback is not an encryption boundary: malware or a compromised phone can read local files.
              • Use a Binance key with Spot trading only, withdrawals disabled, and an IP allowlist where supported. This program never calls the withdrawal API and never asks for a seed phrase or private key.
              • State-changing requests require a same-origin CSRF token; the session cookie is HttpOnly and SameSite=Strict.
              • Live mode is per-session and cannot survive a restart or a lost connection.
